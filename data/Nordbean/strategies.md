# Current product strategies

> Mock data. Nordbean is a fictional company.

Total marketing budget: €20,000 / month. Period: July – October 2026.

## S1. Grow coffee subscriptions through paid search

- **Product:** P1 Coffee Subscription
- **Budget:** €9,000 / month

### Plan

1. Run Google Ads on "kaffee abo" and related head keywords.
2. Offer 50% off the first delivery to new subscribers.
3. Send a 3-email onboarding sequence after the first order.

### Results so far

| Metric | Value |
|--------|-------|
| New subscribers / month | 310 |
| Cost per new subscriber | €29 |
| Churn after first delivery | 34% |
| Average subscriber lifetime | 5.2 deliveries |

## S2. Sell single-origin beans through social media

- **Product:** P2 Single-Origin Beans
- **Budget:** €6,000 / month

### Plan

1. Publish 4 reels per week on Instagram and TikTok about origins and roasting.
2. Work with 3 micro-influencers per month (10k–50k followers).
3. Launch one limited-edition bean per month.

### Results so far

| Metric | Value |
|--------|-------|
| Orders / month from social | 420 |
| Cost per order | €14.30 |
| Average order value | €27 |
| Repeat purchase rate within 60 days | 22% |

## S3. Cross-sell brew gear to existing customers

- **Product:** P3 Brew Gear
- **Budget:** €3,000 / month

### Plan

1. Email gear offers to subscribers after their third delivery.
2. Show gear bundles in the cart.
3. Run retargeting ads for visitors of gear pages.

### Results so far

| Metric | Value |
|--------|-------|
| Gear orders / month | 140 |
| Cost per order | €21.40 |
| Average order value | €46 |
| Gross margin | 18% |

## S4. Test the office coffee plan

- **Product:** P4 Office Coffee Plan
- **Budget:** €2,000 / month

### Plan

1. Landing page for "kaffee fürs büro" with a request-a-quote form.
2. LinkedIn outreach by the founder to office managers in Hamburg and Berlin.

### Results so far

| Metric | Value |
|--------|-------|
| Leads / month | 26 |
| Cost per lead | €77 |
| Lead-to-customer rate | 23% |
| New office customers / month | 6 |
| Average contract value | €210 / month |
| Churn in first 6 months | 5% |
